# Sprint planning

Prepare, then let the owner decide.

1. **Close the last sprint** on its Sprint issue: done, not done, and why.
2. **Carry-over:** each unfinished item with what's left. Anything carried over twice goes back to refinement to be re-split.
3. **Propose the sprint:** only items meeting the Definition of Ready (`spec: accepted`, sized S or M), from the current milestone, must-haves first, within capacity (based on recent sprints).
4. **Sprint goal** in one sentence.
5. **After approval:** create the Sprint issue (label `sprint`) with the goal and scope, set the Iteration on each item if the board is reachable, and list anything that needs refinement before next week.
